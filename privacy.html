Privacy Policy

Last updated: October 18, 2026

Seventeen Booster is a project designed to help creators track social media performance and plan content.

Information We Handle

The current Python prototype allows users to enter video views, likes, and follower counts. These entries are saved in a CSV file named stats.csv on the user's own computer.

How Information Is Used

The locally saved statistics are used to display a user's recorded results and help them review their content performance.

Data Sharing

The current prototype does not transmit these manually entered statistics to a Seventeen Booster server. It does not currently connect to or access TikTok account data.

Data Security and Retention

Local statistics remain in the user's files until the user deletes them. Users should protect their computers and avoid sharing files containing information they wish to keep private.

Third-Party Services

This project is hosted using GitHub Pages. Website visitors' interactions with the hosting service are subject to GitHub's applicable privacy practices. TikTok is a separate service.

Future Features

If future versions introduce account connections, online storage, or access to TikTok data, this policy will be updated to describe the information collected, how it is used, and how it is shared before those features are offered.
